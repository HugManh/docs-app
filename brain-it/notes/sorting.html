Chương 12. Sorting

Purpose

Sorting xác định thứ tự trả về của Collection.

Một quy ước Sorting thống nhất giúp:

  • Kết quả ổn định giữa các lần gọi API.
  • Pagination hoạt động chính xác.
  • Client dễ dàng thay đổi cách hiển thị.
  • Database dễ tối ưu bằng Index.

Sorting chỉ thay đổi thứ tự dữ liệu, không thay đổi nội dung Resource.

Rules

  • Sorting MUST sử dụng Query Parameter.
  • Collection Endpoint SHOULD hỗ trợ Sorting.
  • Pagination MUST đi kèm Sorting xác định.
  • API SHOULD hỗ trợ nhiều trường Sort.
  • API MUST Validate Sort Field.
  • Không cho phép Client truyền SQL hoặc biểu thức tùy ý.

Sort Direction

Không khuyến nghị

sort=name

order=desc

Khuyến nghị

sort=-name

Đơn giản hơn.

Sorting by Enum

Ví dụ

GET /courses?sort=level

Nếu Enum có thứ tự nghiệp vụ (N5 → N1), cần tài liệu hóa cách sắp xếp hoặc xử lý riêng trong Database.

Sorting by Nested Fields

Ví dụ

GET /orders?sort=customerName

Thay vì

sort=customer.name

Khuyến nghị chỉ hỗ trợ nếu Backend thực sự tối ưu được Join và có tài liệu rõ ràng.

Unknown Sort Field

Ví dụ

GET /users?sort=password

Không bỏ qua âm thầm.

Best Practices

  • Chuẩn hóa tham số sort.
  • Dùng - cho thứ tự giảm dần.
  • Luôn có Default Sort.
  • Pagination luôn đi kèm Sorting ổn định.
  • Validate Sort Field theo Allow List.
  • Thiết kế Index cho các trường Sort phổ biến.
  • Hỗ trợ nhiều trường Sort khi cần.
  • Không cho Client truyền biểu thức SQL.

Checklist

  • Sử dụng sort làm Query Parameter.
  • Hỗ trợ ASC và DESC.
  • Có Default Sort.
  • Sorting ổn định (Stable Sorting).
  • Có Allow List cho Sort Field.
  • Có Index hỗ trợ Sorting.
  • Hoạt động cùng Filtering, Searching và Pagination.
  • Không cho phép SQL Injection qua Sort.
  • Tài liệu hóa quy tắc sắp xếp với NULL và Enum nếu có.

Lưu ý: Trong các chương tiếp theo (Field Selection, Include/Expand, Nested Resources), toàn bộ cơ chế truy vấn Collection sẽ được hoàn thiện theo một chuẩn thống nhất:

Filtering → Searching → Sorting → Field Selection → Include → Pagination → Response.

Đây là pipeline được nhiều API Enterprise hiện đại áp dụng để đảm bảo tính nhất quán, khả năng mở rộng và hiệu năng.
