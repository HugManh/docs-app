Chương 6. Status Codes

Ghi chú bổ sung: Trong các chương sau (Validation, Error Handling, Optimistic Locking…), tài liệu sẽ mở rộng cách sử dụng các mã như 412 Precondition Failed, 428 Precondition Required, 429 Too Many Requests và chuẩn hóa cấu trúc JSON của error response. Điều này giúp thống nhất từ HTTP Status Code đến nội dung lỗi trả về.
