CertNet API Contract

Mục đích: Contract để ghép (integrate). Không phải whitepaper, không phải guide triển khai chain. Spec sớm — testnet sau.

Overview: What-is-CertNet · OpenAPI máy đọc: openapi.yaml · Bản trong code: certnet-chain/docs/openapi.yaml

0. Nguyên tắc tích hợp

Nguyên tắcÝ nghĩa cho integrator
CertNet = shared trust layerMega app / wallet / verifier là client, không hard-wire backend CertNet vào core
Trước GĐ7Chỉ phụ thuộc interface: DidResolver, StatusChecker, TrustRegistry
Spec trước, testnet sauContract này đủ mock / stub / adapter; endpoint thật đến khi testnet sẵn
Public read, permissioned writeRead không cần auth; write cần chữ ký / quyền (xem §4)
Không PII trên chainResponse chỉ có key, status, trust — không họ tên / CCCD

Adapter pattern: Implement interface bằng mock local → swap sang HTTP Gateway khi có testnet. Không đổi code verify/wallet ngoài adapter. Xem Interface-decoupling.

Với response claim chain-backed, bổ sung object chain (self-check):

3. Ba surface đọc / verify (bắt buộc để ghép)

3.1 Interface TypeScript (logical)

Gateway HTTP bên dưới map 1–1 với các method trên.

3.2 DidResolver

Resolve did:certnet:... → DID Document.

MethodGET
Path/dids/{did}
QueryversionTime (ISO 8601, optional) — resolve document tại thời điểm

{did}: URL-encode toàn bộ DID (did%3Acertnet%3A...).

DID syntax (contract tối thiểu)

SegmentVí dụGhi chú
methodcertnetcố định
networklocal | testnet | mainnetBắt buộc (chốt 25/11)
unique-idhex 16 ký tự (gateway sinh) hoặc label (fixture)Opaque string, ký tự A-Za-z0-9-_ (chốt 25/11)

Response 200

Curves bắt buộc hỗ trợ trong verificationMethod: Ed25519 (OKP) và P-256 (EC).

ErrorKhi
DID_INVALIDSyntax sai method / segment
DID_NOT_FOUNDChưa đăng ký
VERSION_TIME_UNSUPPORTEDClient gửi versionTime trước khi gateway hỗ trợ
VERSION_NOT_FOUNDKhông có version tại versionTime

3.3 StatusChecker

Check trạng thái credential: valid | suspended | revoked.

MethodGET
Path/credential-statuses/{statusListId}
Queryindex (required, integer ≥ 0)

Hoặc batch (tuỳ chọn, cùng contract):

MethodPOST
Path/credential-statuses/check
Body{ "statusListId", "index" } hoặc { "items": [ ... ] }

VC tham chiếu status (placeholder)

Format list on-chain (chốt 25/11): map index → status lưu JSON trong KV store, không phải Bitstring / Token Status List. Contract cố định ba trạng thái kết quả và API check; có thể đổi encoding sau mà giữ statusListId + index. Chi tiết: Credential-Status.

Response 200

status enum: valid | suspended | revoked.

3.4 TrustRegistry

Lookup issuer DID: được công nhận hay bị từ chối; kèm scope / loại VC / thời hạn / cơ quan công nhận.

MethodGET
Path/trust-registry/issuers/{issuerDid}
QueryvcType (optional), atTime (ISO 8601, optional)
  • recognition: recognized | rejected → 200
  • Không có record → 404 ISSUER_NOT_FOUND

Chi tiết schema: openapi.yaml.
